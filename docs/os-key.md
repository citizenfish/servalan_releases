# How to get a free OS key

OS Outdoor is Ordnance Survey's own map of England, Scotland and Wales. It isn't the same as the paper Explorer maps. To show OS maps or the other OS styles, Servalan needs a key from Ordnance Survey, which is free. Getting one takes a few minutes.

A key is a long line of letters and numbers that lets Servalan show OS maps and the other OS styles for you. Ordnance Survey's pages call it the "Project API Key".

1. **Make a free account.** Open the [OS Data Hub](https://osdatahub.os.uk/) and sign up. When it asks for a plan, choose "OS OpenData", which is free. If you already have an account, log in.
2. **Make a project.** Choose "Data", then "APIs", then "API Projects", then "Create a new project". Give it a name, such as Servalan, and choose "Create project".
3. **Add maps to the project.** Choose "+ Add an API to this project", pick "OS Maps API", choose "Add to project", and then "Done".
4. **Copy the project's key.** The project's page shows its "Project API Key". Copy all of it.
5. **Paste it into Servalan.** In Servalan, open Settings, then Maps and offline. Paste the key into the box and save it. OS maps and the other OS styles can then be chosen like any other map.

## What the free plan covers

The free plan covers OS maps and the other OS styles for the whole of England, Scotland and Wales. As you zoom in, each stops adding detail at a certain point.

It doesn't cover the OS Explorer 1:25,000 detail, which comes with Ordnance Survey's Premium maps. If your key includes them, OS maps go closer in, to Explorer detail, and the closer zooms count against your monthly Premium allowance from Ordnance Survey.

OS maps and the other OS styles need an internet connection. Servalan can't save them for use offline.

## Your key

Your key stays on your computer, in its password store. Servalan sends it only to Ordnance Survey, to fetch OS maps and the other OS styles. You can remove it in Settings at any time.

Ordnance Survey can see which areas of the map you look at.

*These steps were checked on 29 September 2026. If the OS Data Hub looks different, its own help has the latest steps.*
